# Photos

Drop a photo here and it replaces the matching branded panel automatically. The file name (without extension) is the slot name; `.jpg`, `.jpeg`, `.png` or `.webp` all work.

| File name | Where it shows |
| --- | --- |
| `hero` | Home page hero (mother and baby, or caregiver with child) |
| `babysitting` | Babysitting card + page |
| `home-cleaning` | Home cleaning card + page |
| `elderly-companionship` | Elderly companionship card + page |
| `pet-sitting` | Dog & cat sitting card + page |
| `pick-up-drop-off` | Pick-up & drop-off card + page |
| `errands` | Errands card + page |
| `trust` | Home page "background-checked" section |

Rules: see `docs/build/imagery.md` (modest, Gulf home settings, bright and warm).
